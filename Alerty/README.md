# Alerty

Alerty — кроссплатформенная панель для наблюдения за серверами, контейнерами и сервисами и безопасного управления ими. Проект нацелен на удобный единый интерфейс для системных метрик, логов в реальном времени, статуса сервисов и контролируемых административных действий.

Текущая версия: **0.0.1f** — обновлённая чёрно-оранжевая тема, анимации интерфейса и группировка логов по времени или серверу.

## Возможности прототипа

- обзор состояния серверов, сервисов, событий и системных ресурсов;
- анимированный график CPU/RAM и поток демонстрационных логов;
- список серверов с Linux и Windows;
- отдельные каталоги серверов, событий, живых логов и действий с поиском и фильтрами;
- переходы от сервера к его сервисам и метрикам, от события к логам, фиксация демо-действий в аудите;
- группировка лога по часовым интервалам или по серверам, сворачивание групп и фильтрация;
- подтверждение команды перезапуска сервиса в демо-режиме;
- адаптивная раскладка для широкого и мобильного экрана.

## Запуск

Откройте `index.html` в браузере или запустите статический сервер из этой папки, например `python -m http.server 8080`, затем откройте `http://localhost:8080`.

## Важно

Релиз **0.0.1f** остаётся локальной демонстрацией: телеметрия, события, логи и аудит синтетические, а команды управления не отправляются на реальные хосты. Метрики сравниваются по трём демонстрационным серверам; вкладки CPU, RAM и Load Average переключают временной график. Закреплённые сервисы сохраняются локально в браузере. По roadmap впереди API, безопасная регистрация устройств, серверное хранилище и подключение Prometheus/Loki и ограниченного агента узла. Для реального управления Docker нельзя открывать daemon без защиты: доступ к нему фактически даёт широкие права на хост.

## Направление архитектуры

- интерфейс: web dashboard, доступный с ПК и мобильного браузера;
- серверная часть: API и PostgreSQL для учётных записей, хостов, устройств и аудита;
- метрики: Prometheus, `node_exporter` / `windows_exporter`, cAdvisor;
- логи: Loki и Grafana Alloy;
- графики: собственные обзорные карточки плюс Grafana для расширенного анализа;
- управление: отдельный узловой агент с минимальным набором разрешённых операций и защищённым соединением.
