# Alerty

Alerty — кроссплатформенная панель для наблюдения за серверами, контейнерами и сервисами и безопасного управления ими. Проект нацелен на удобный единый интерфейс для системных метрик, логов в реальном времени, статуса сервисов и контролируемых административных действий.

Текущая версия: **0.0.2b** — подготовлен локальный Compose-стек Prometheus/Loki для домашней лабы на Proxmox и шаблоны подключения Linux/Windows узлов.

## Возможности прототипа

- обзор состояния серверов, сервисов, событий и системных ресурсов;
- анимированный график CPU/RAM и поток демонстрационных логов;
- список серверов с Linux и Windows;
- отдельные каталоги серверов, событий, живых логов и действий с поиском и фильтрами;
- переходы от сервера к его сервисам и метрикам, от события к логам, фиксация демо-действий в аудите;
- группировка лога по часовым интервалам или по серверам, сворачивание групп и фильтрация;
- подтверждение команды перезапуска сервиса в демо-режиме;
- адаптивная раскладка для широкого и мобильного экрана.
- контейнерный шлюз проверяет доступность Prometheus/Loki и проксирует их query API;
- отдельная VM в Proxmox может запускать Alerty, Prometheus и Loki; exporters и Alloy устанавливаются на самих наблюдаемых узлах;

## Развёртывание

Пошаговая схема VM, Compose, targets, exporters, Alloy, Nginx и WireGuard описана в [DEPLOYMENT.md](DEPLOYMENT.md).

Кратко: создать отдельную Debian/Ubuntu VM на Proxmox, получить репозиторий, скопировать `.env.example` в `.env`, добавить реальные серверы в `monitoring/targets/nodes.json` и запустить `docker compose up -d --build`. Для контейнера Alerty Prometheus и Loki доступны через внутренние имена `prometheus` и `loki`.

По умолчанию порт опубликован только на `127.0.0.1`. Для удалённого доступа используйте VPN и TLS Nginx с авторизацией; пример location-конфигурации находится в `deploy/nginx-alerty-location.conf`. Не публикуйте Prometheus или Loki напрямую в интернет. Файл `.env` игнорируется Git и не должен отправляться в репозиторий.

При локальном открытии `index.html` без контейнера интерфейс остаётся в демонстрационном режиме. Эндпоинты интеграции доступны только при запуске через Node/Docker.

## Важно

В **0.0.2b** Compose поднимает Alerty, Prometheus и Loki с постоянными томами. Targets оставлены пустыми до получения адресов и ОС узлов. Чтобы реальные метрики появились в интерфейсе, нужно установить exporters, внести targets и затем связать их labels с запросами UI. Реальные логи попадут в Loki после установки Alloy на узлы. Управляющие команды на хосты пока не отправляются.


## Направление архитектуры

- интерфейс: web dashboard, доступный с ПК и мобильного браузера;
- серверная часть: API и PostgreSQL для учётных записей, хостов, устройств и аудита;
- метрики: Prometheus, `node_exporter` / `windows_exporter`, cAdvisor;
- логи: Loki и Grafana Alloy;
- графики: собственные обзорные карточки плюс Grafana для расширенного анализа;
- управление: отдельный узловой агент с минимальным набором разрешённых операций и защищённым соединением.
