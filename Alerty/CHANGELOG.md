# История изменений Alerty

Все заметные изменения проекта фиксируются здесь. Записи сгруппированы по версиям, новые версии добавляются сверху. Названия и номера релизов задаёт владелец проекта.

## 0.0.2c — 2026-11-13

### Добавлено

- Стек Alerty/Prometheus/Loki подготовлен для размещения непосредственно на Ubuntu 101.
- Добавлен Node Exporter 1.12.1 контейнер с read-only доступом к host `/proc`, `/sys` и rootfs; Prometheus собирает первый узел по адресу внутри Compose-сети.
- Добавлен Alloy 1.21.3 контейнер, который читает journald Ubuntu 101 и отправляет записи в локальный Loki с меткой `host=ubuntu-101`.
- В target метка host задаётся как `ubuntu-101`, os — `linux`.
- Версия UI и документации обновлена до 0.0.2c.

### Статус установки

- Конфигурация подготовлена, но на реальный Ubuntu 101 стек пока не устанавливался: из рабочего окружения нет доступа к серверу.

### Ограничения

- Другие два сервера ещё не добавлены: нужны их ОС и адреса, а также установка подходящего exporter.
- Графики Alerty пока не переключены на данные Prometheus; сами данные доступны в Prometheus после запуска стека.

## 0.0.2b — 2026-11-13

### Добавлено

- Compose развёртывание включает Alerty, Prometheus 3.13.3 и Loki 3.7.0 с постоянными томами и ограниченным loopback-доступом к интерфейсам источников.
- Prometheus читает file-based discovery targets из `monitoring/targets`; список реальных хостов оставлен пустым.
- Loki настроен на локальное файловое хранилище с 14-дневным сроком хранения и compactor.
- Добавлены шаблоны Alloy для journald и Windows Event Log, а также Nginx Basic Auth/TLS маршрут для Loki ingest.
- Добавлено руководство по отдельной VM на Proxmox и WireGuard доступу.
- Версия интерфейса и документации обновлена до 0.0.2b.

### Граница релиза

- В реальной лабе ничего не устанавливалось: нет доступа к Proxmox и адресов трёх узлов.
- Экранные графики и логи не переключены с демо до установки exporters/Alloy и получения ОС/labels узлов.

## 0.0.2a — 2026-11-13

### Добавлено

- Node.js HTTP-шлюз для одно-origin работы UI и API, с ограниченным набором прокси-маршрутов к Prometheus и Loki.
- Проверка доступности обоих источников через `/api/integrations`; статусы отображаются в боковой панели.
- Адреса и upstream credentials читаются только из env; добавлен `.env.example`, реальный `.env` исключён из Git.
- Dockerfile и Compose с запуском от непривилегированного пользователя, read-only filesystem, без capabilities и публикацией порта только на loopback.
- Пример размещения за Nginx Basic Auth и заметки по подготовке домашней лаборатории.

### Граница релиза

- Шлюз подключает API и проверяет источники, но текущие графики и лента пока не читают их данные; отображаемая телеметрия остаётся демо до согласования labels и queries.
- Серверная регистрация устройств, база, WebAuthn и ограниченный агент управления — следующие пункты плана.

## 0.0.1f — 2026-11-13

### Добавлено и изменено

- В логе есть режим группировки по часовым интервалам и отдельный режим группировки по серверу.
- Группы можно сворачивать; счётчики отражают количество записей после активных фильтров.
- Для каждой записи сохраняется временная метка, порядок событий хронологический.
- Интерфейс переработан в чёрно-оранжевой палитре; добавлены анимации появления разделов, карточек и логов.
- Учтена настройка устройства «уменьшить движение» для анимаций.
- Версия интерфейса и документации обновлена до 0.0.1f.

### Ограничения

- Источник логов пока демонстрационный; реальная интеграция с Loki остаётся задачей следующего этапа roadmap.

## 0.0.1e — 2026-11-13

### Добавлено

- Серверы, события, живые логи и аудит получили отдельные страницы с собственным содержимым.
- Каталог серверов показывает ресурсы каждого узла; доступны фильтр ОС, поиск и переходы к его сервисам и метрикам.
- События можно фильтровать, закрывать и открывать логи соответствующего сервера.
- В консоли логов добавлены поиск, фильтры уровня/сервера и пауза потока.
- Журнал действий получил поиск, фильтры и записи о подтверждённых демо-командах и закрытых событиях.
- Версия интерфейса и документации обновлена до 0.0.1e.

### Ограничения

- Данные и действия остаются демонстрационными и сбрасываются после перезагрузки страницы.
- Подключение реальных серверов, постоянный аудит и выполнение команд требуют backend API и агента.

## 0.0.1d — 2026-11-13

### Изменено

- Карточки «Серверы», «Сервисы», «Оповещения» и «События за час» на обзоре открывают соответствующие разделы.
- Кнопки перехода в метрики, сервисы, события и логи связаны с разделами приложения.
- Иконки поиска и уведомлений ведут в каталог сервисов и события.
- Карточки обзора доступны с клавиатуры через Enter и пробел.
- Добавлены стрелки-подсказки и состояния наведения/фокуса на элементах перехода.

## 0.0.1c — 2026-11-13

### Добавлено

- Отдельная вкладка «Метрики» в навигации.
- Переключение графика между CPU, RAM и Load Average по образцу вкладок ресурсов в диспетчере задач.
- Три временных ряда на общей шкале: prod-eu-01, prod-eu-02 и win-build-01.
- Легенда с текущими значениями, подписи шкалы под выбранную метрику и сводка текущего состояния каждого сервера.
- Демо-значения обновляются вместе с графиком.

### Ограничения

- Данные синтетические; настоящий сбор Prometheus ещё не подключён.
- Load Average для Windows в демонстрации служит условным сравнительным рядом; при подключении реальных хостов Windows потребуется показывать подходящий показатель нагрузки, так как стандартный Unix Load Average там отсутствует.

## 0.0.1b — 2026-11-13

### Изменено

- Основной шрифт заменён на Inter; увеличены подписи, заголовки, элементы навигации и ключевые числа.
- Добавлен отдельный каталог сервисов с фильтрами Docker/systemd и поиском.
- Добавлено закрепление сервисов звёздочкой и блок быстрых карточек на главной.
- Закрепление привязано к паре «сервер/сервис», хранится в localStorage и переживает перезагрузку страницы.
- Перезапуск доступен из карточки закреплённого сервиса и требует подтверждения.
- Обновлены версия в интерфейсе и релизное описание.

### Ограничения

- Сервисный каталог демонстрационный. Закрепления хранятся только в текущем браузере, не синхронизируются между устройствами.
- Кнопка перезапуска пока не отправляет команду на реальный хост.

## 0.0.1a — 2026-11-13

Первый интерактивный прототип продукта.

### Добавлено

- Обзор инфраструктуры с карточками серверов, сервисов, событий и доступности.
- Демонстрационный график использования CPU и RAM с обновлением в реальном времени.
- Поток синтетических логов с уровнями INFO, WARN и ERROR.
- Таблица тестовых Linux- и Windows-серверов.
- Подтверждение команды перезапуска сервиса с демонстрационным результатом.
- Панель доверенных устройств: список, добавление и отзыв устройства в браузерной демо-сессии.
- Поле MAC-адреса как справочная метка для локальной сети.
- Адаптивная раскладка для широкого и мобильного экрана.

### Ограничения

- Метрики, логи, серверы, события входа и действия полностью демонстрационные.
- Команда перезапуска не отправляется на настоящий сервер.
- Доверенные устройства не сохраняются на сервере; passkey/WebAuthn ещё не подключён.
- MAC-адрес не подтверждает личность устройства через интернет и не является механизмом удалённой аутентификации.
- API, PostgreSQL, Prometheus, Loki, Grafana, Docker-интеграция и узловой агент пока не подключены.

### Архитектурное направление

- Web-интерфейс для ПК и мобильных браузеров.
- API и PostgreSQL для учётных записей, серверов, доверенных устройств и аудита.
- Prometheus с экспортёрами для системных и контейнерных метрик.
- Loki и Grafana Alloy для централизованных логов.
- Узловой агент с защищённым исходящим подключением и ограниченным списком разрешённых действий.
