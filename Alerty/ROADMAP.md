## Принципы безопасности

- Не публиковать Docker daemon API напрямую в интернет.
- MAC-адрес использовать только как справочный атрибут или дополнительный LAN-фильтр.
- Для доверия устройству использовать криптографическую регистрацию, а для чувствительных действий — повторное подтверждение.
- Все удалённые действия ограничивать разрешёнными операциями и записывать в аудит.
- Секреты, ключи и токены не хранить в репозитории.
